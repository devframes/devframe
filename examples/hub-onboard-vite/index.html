Hub onboarding (Vite)

This host ships only @devframes/hub-ui-onboard. The button at the bottom left:

  • is /__devframes/embedded.js, a 20 kB stand-in for the hub UI
  • installs @devframes/hub, @devframes/hub-ui and @devframes/plugin-git when you click Install
  • then hands /__devframes/ to the real hub in this same process, no restart
  • writes node_modules/.devframe/hub-ui-onboard.json when you click Disable
