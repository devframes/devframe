## Message

> Nobody allowed `{command}` within `{minutes}` minutes. The install was refused.

## Cause

Each install that the panel asks for needs the developer's permission ([DF9005](/errors/DF9005)). Without an `onConfirm` option, `createOnboarding()` asks in the terminal and waits 5 minutes for an answer. Nobody answered in that time, so the install is refused, and the panel tells the user.

Sometimes the answer cannot arrive. Another process can read the same terminal before the dev server does. For example, `nuxi dev` in plain mode moves the dev server to a child process after a restart, and the parent process reads each line for its own shortcuts.

## Fix

Click Install again, then type `y` and press Enter in the terminal that runs the dev server. If the answer still does not arrive, run the command from the panel in a terminal yourself. If you maintain the host, pass an `onConfirm` function to `createOnboarding()` that asks through the CLI that owns the terminal.

## Source

- [`packages/hub-ui-onboard/src/terminal-confirm.ts`](https://github.com/devframes/devframe/blob/main/packages/hub-ui-onboard/src/terminal-confirm.ts): `confirmInTerminal()` reports this and returns `false` when no line arrives in time.
