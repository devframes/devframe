## Message

> Five wrong onboarding codes were entered. Install and Disable are blocked until the dev server restarts.

## Cause

Install and Disable need the code that [DF9005](/errors/DF9005) prints. After five wrong codes, `createOnboarding()` refuses both actions for the rest of the process, so nobody can guess the code.

## Fix

Restart the dev server. It prints a new code the next time you click Install or Disable entirely. If you did not enter the wrong codes, another device or page can reach this dev server: bind it to `localhost`. You can also run the install command from the panel in a terminal.

## Source

- [`packages/hub-ui-onboard/src/index.ts`](https://github.com/devframes/devframe/blob/main/packages/hub-ui-onboard/src/index.ts): `authorize()` reports this on the fifth wrong code, then answers each later Install or Disable with status 429 and this code.
