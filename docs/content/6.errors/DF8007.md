---
title: 'DF8007: Devframe Skipped by the Static Hub Build'
description: 'Devframe "{name}" ({id}) declares `capabilities.build: false`, so the static hub build skips it.'
---

## Message

> Devframe "`{name}`" (`{id}`) declares `capabilities.build: false`, so the static hub build skips it.

## Cause

A devframe whose value is inherently live - a terminal over PTY sessions, a proxy in front of a running process - declares `capabilities.build: false` on its definition. `buildHub` honors the declaration by leaving the devframe out of the static output entirely: its SPA is not copied, its dock is not registered (so it never appears in the baked `devframe:docks` shared state or `__index.json`), and its `setup(ctx)` never runs, so none of its RPCs join the static dump. This log line records each skip so a missing dock in a static build is traceable.

The built-in terminals, code-server, and assets devframes declare this capability.

## Example

```ts
await buildHub({
  outDir: 'dist/__devframes',
  devframes: [
    createA11yDevframe(), // baked
    createTerminalsDevframe(), // `capabilities.build: false` -> DF8007, skipped
  ],
})
```

## Fix

Nothing to fix - this is the declared behavior. If the tool does have a meaningful baked form (its panels read from `static`/`snapshot` RPCs), drop `capabilities.build: false` from the definition so the static build includes it.

## Source

- [`packages/hub/src/node/install-devframe.ts`](https://github.com/devframes/devframe/blob/main/packages/hub/src/node/install-devframe.ts): `prepareDevframe()` logs this and skips the mount for a `capabilities.build: false` definition in a `mode: 'build'` hub context.
