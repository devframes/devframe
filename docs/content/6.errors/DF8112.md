---
title: 'DF8112: Legacy Dock Settings Unreadable'
description: 'Could not read the legacy dock settings file "{filepath}"'
---

## Message

> Could not read the legacy dock settings file "`{filepath}`"

## Cause

The hub seeds its initial dock layout once from the `settings.json` an earlier version kept in the old machine-wide project directory. That file exists, but it is not valid JSON, or it could not be read (permissions, or a directory in its place).

The one-time fallback is temporary and goes away in a later release. Writes always go to the new per-checkout `settings.json`.

## Fix

The hub starts from default dock settings. Delete or fix the legacy file to silence the warning: nothing else reads it, and the new per-checkout file is authoritative once it exists.

## Source

- [`packages/hub/src/node/host-docks.ts`](https://github.com/devframes/devframe/blob/main/packages/hub/src/node/host-docks.ts): `readLegacyUserSettings()` reports this when reading or parsing the legacy file fails, and `DevframeDocksHost.init()` then keeps `DEFAULT_STATE_USER_SETTINGS()`.
