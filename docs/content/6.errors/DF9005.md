## Message

> A browser asked to `{action}`. To allow it, enter this code in the panel: `{code}`

## Cause

Install and Disable change the project, and a dev server can listen on the network. So the onboarding panel must send a 6-digit code that only the terminal shows. A request to `POST <base>__onboard/install` or `POST <base>__onboard/disable` came without the `x-devframes-onboard-code` header, and `createOnboarding()` printed the code. The code stays the same until the process exits.

## Fix

If you clicked Install or Disable entirely, type the code into the panel. If you did not, another device or page can reach this dev server. Do not enter the code anywhere, and bind the dev server to `localhost`.

## Source

- [`packages/hub-ui-onboard/src/index.ts`](https://github.com/devframes/devframe/blob/main/packages/hub-ui-onboard/src/index.ts): `authorize()` prints this and answers with status 401 when the request has no code.
