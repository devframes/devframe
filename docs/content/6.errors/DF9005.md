## Message

> A browser asked to run `{command}`. Type y and press Enter to allow it.

## Cause

Install changes `package.json` and the lockfile, and a dev server can be reachable from other devices. So each install that the panel asks for needs the developer's permission. The panel's `POST <base>__onboard/install` waits until you answer. Without a `confirm` option, `createOnboarding()` asks in the terminal that runs the dev server.

## Fix

If you clicked Install, type `y` and press Enter. Any other answer refuses the install, and the panel tells the user. If you did not click Install, press Enter. Another device or page can reach this dev server, so bind it to `localhost`.

To ask in another way, for example with your own logger, pass a `confirm` function to `createOnboarding()`.
