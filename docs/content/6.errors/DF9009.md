---
title: 'DF9009: Install Command Timed Out'
description: 'The package manager did not finish in time, so the install was stopped.'
---

## Message

> `{command}` did not finish within `{seconds}` seconds, so it was stopped.

## Cause

The Install button ran the project's package manager, and the package manager did not exit before the time limit. The limit is the `installTimeout` option of `createOnboarding()`. The default is 10 minutes. The onboarding then stopped the process, so the panel does not wait forever.

Usually the package manager hangs. For example, some pnpm 10 versions hang while they resolve some prerelease versions. A slow network or a very large install can also take longer than the limit.

## Fix

Run the command shown in the panel in a terminal to see where the package manager stops. Fix the cause, for example update the package manager, then click Retry. If the install is only slow, pass a larger `installTimeout` to `createOnboarding()`.

## Source

- [`packages/hub-ui-onboard/src/install.ts`](https://github.com/devframes/devframe/blob/main/packages/hub-ui-onboard/src/install.ts): `runInstall` stops the process and throws this when the time limit ends. The status route reports it as `{ state: 'error', error: { code, message } }`.
