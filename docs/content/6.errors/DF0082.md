## Message

> Request access authorization failed on a WebSocket connection.

## Cause

The server-side request access callback threw an error or rejected its promise during an upgrade or an inbound message. The socket is rejected or closed before the request can reach RPC dispatch. The diagnostic retains the original error as its cause.

## Example

```ts
initHub({
  access: {
    authorize: async () => await checkInternalAccess(),
  },
})
```

## Fix

Inspect the reported cause and repair the callback or its dependency. Return `false` for an expected denial.

## Source

- [`packages/devframe/src/rpc/transports/ws-server.ts`](https://github.com/devframes/devframe/blob/main/packages/devframe/src/rpc/transports/ws-server.ts) reports callback failures during upgrades and inbound messages.
