`createCac`'s building block: h3 + WebSocket RPC + the SPA at the resolved base path.

```ts
import { createDevServer } from 'devframe/adapters/dev'
import myDevframe from './my-tool'

const handle = await createDevServer(myDevframe, {
  port: 7777,
  onReady: ({ origin }) => console.log(`Ready at ${origin}`),
})

// graceful shutdown: SIGINT, hot reload, test teardown
process.on('SIGINT', () => handle.close().then(() => process.exit(0)))
```

The returned `StartedServer` exposes `origin`, `port`, `app`, `rpcGroup`, `connectionMeta()` and `close()`. Its `ws` property is optional. Call `close()` to release the HTTP listener even with WebSocket disabled.

Each call to `handle.connectionMeta()` returns a fresh JSON snapshot. Resolve local WebSocket, SSE and MCP paths against `handle.origin`. When reading `__connection.json` over HTTP, resolve its relative paths against the document URL.

| Option | Default | Description |
|--------|---------|-------------|
| `host` | `def.cli?.host ?? 'localhost'` | Bind host. |
| `port` | resolved via `resolveDevServerPort` | Listen port. |
| `flags` | `{}` | To `setup(ctx, { flags })`. |
| `distDir` | `def.clientAssets` | SPA dist; unset = bridge mode. |
| `basePath` | `resolveBasePath(def, 'standalone')` | Mount override. |
| `app` | fresh h3 app | Mount onto. |
| `openBrowser` | resolves from `flags.open` / `def.cli?.open` | `false` off; string opens a path. |
| `ws` | `def.cli?.ws` | RPC WebSocket; see below. |
| `onReady` | none | WS-bind callback. |

## WebSocket endpoint

By default the RPC socket shares the HTTP port. The discovery document advertises its relative path as `__ws`. Configure `def.cli.ws`:

| Field | Scenario | Advertised `websocket` |
|-------|----------|------------------------|
| `route` | same server, other route | `{ path: <route> }` |
| `port` | different port | `{ port, path: <route> }` |
| `url` | remote origin | URL verbatim |

Precedence `url` > `port` > `route`; `url` keeps the socket local on `route`.

## Port resolution

`resolveDevServerPort(def, opts?)` resolves a port before start.

```ts
import { resolveDevServerPort } from 'devframe/adapters/dev'

const port = await resolveDevServerPort(myDevframe, { host: '127.0.0.1' })
// honors def.cli?.port / portRange / random
```

| Option | Default | Description |
|--------|---------|-------------|
| `host` | `def.cli?.host ?? 'localhost'` | Bind host (`get-port-please` detection). |
| `defaultPort` | `def.cli?.port ?? 9999` | Preferred-port override. |
